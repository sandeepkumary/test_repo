## Basic Pacman Game

This repository contains a basic Pacman game implemented in HTML, CSS, and JavaScript.

### How to Run

1. Open `index.html` in a web browser.
2. Use arrow keys to move Pacman.
3. Eat the white dots to score points.
4. Avoid the red ghost.

### GitHub Pages

To run this game from GitHub Pages:
1. Push this repository to GitHub.
2. Go to the repository settings.
3. Enable GitHub Pages and select the main branch.
4. The game will be available at `https://yourusername.github.io/repository-name/`
